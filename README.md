# Niljyoti Travels — Car & Van Rentals Platform (Tripura & North East India)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/BrintaDeb/niljyoti_demo)

A production-ready, modern editorial car and van rental platform for **Niljyoti Travel Agency** ([niljyotitripura.com](https://niljyotitripura.com/)), the pioneer car rental service provider in Tripura and Northeast India since 2007.

## 🌟 Key Features

1. **Authentic Client Brand Identity**:
   - Exact intact original logo from `niljyotitripura.com` (`/images/logo.png`).
   - Official client color palette: `#189cf4` (Azure Blue), `#02b3e4` (Cyan), `#163b5c` (Logo Navy), `#33334f` (Deep Slate), `#edf1f7` (Light Canvas).
2. **Complete 23-Vehicle Verified Fleet**:
   - All authentic client models (Swift, WagonR, Eeco, Tigor, Dzire, Dzire Aura, Ertiga, Rumion, Scorpio N, Scorpio, Bolero, Bolero Neo, Innova Crysta, Hycross, Fortuner, Thar, Thar Roxx, XL6, Tempo Traveller, Bus 45-Seater, Big Bus, BMW, Audi).
   - Dedicated, verified model photography for every vehicle. Zero mock data.
3. **Production 5-Step Checkout Engine**:
   - Floating interactive Booking Pod.
   - Protection plans (Basic, Smart Cover, Zero-Depreciation).
   - Add-on extras (GPS, Child Seat, MBB Airport Fast-Track).
   - Renter KYC verification & itemized tax invoice generation.
4. **Self-Service "Manage Booking" Portal**:
   - Real-time reservation lookup by Booking Reference ID (`NIL-2026-XXXX`) and phone number.
5. **Live Multi-Currency Engine**:
   - Instant dynamic switching between INR (₹), USD ($), EUR (€), and GBP (£).
6. **Tour Packages & Media Showcases**:
   - Verified Darjeeling Tour Package with itinerary and pricing.
   - Responsive YouTube video media showcase and Government/PSU accreditation badges.
7. **Interactive 3D Three.js Visuals**:
   - Endless 3D highway with speed particles and live IXA Airport waypoint marker.
